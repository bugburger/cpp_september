## 1. 栈内存与堆内存

普通局部变量通常具有自动存储期：

```cpp
void test()
{
    int value = 10;
}
```

进入作用域时，`value` 开始存在；离开作用域时，它会自动销毁，不需要手动释放。

动态对象通过 `new` 创建：

```cpp
int* p = new int(20);
```

这里需要区分两个对象：

* 指针变量 `p` 是局部变量，通常位于栈中。
* `new int(20)` 创建的整数对象位于堆中。
* `p` 保存堆对象的地址。
* `*p` 表示访问堆对象中的值。

堆对象不会因为局部指针离开作用域而自动释放，必须使用 `delete`，或者交给后续学习的 RAII 和智能指针管理。

## 2. new 与 delete

创建一个动态对象：

```cpp
int* p = new int(20);
```

访问对象：

```cpp
std::cout << *p << '\n';
```

释放对象：

```cpp
delete p;
p = nullptr;
```

`delete p` 释放的是 `p` 指向的堆对象，不是指针变量 `p` 本身。

释放后将指针设为 `nullptr`，可以减少继续误用旧地址的风险。

## 3. new[] 与 delete[]

创建动态数组：

```cpp
int* numbers = new int[5]{10, 20, 30, 40, 50};
```

访问数组元素：

```cpp
std::cout << numbers[0] << '\n';
```

释放动态数组：

```cpp
delete[] numbers;
numbers = nullptr;
```

创建和释放必须严格匹配：

```text
new      → delete
new[]    → delete[]
```

`new[]` 创建一组对象，`delete[]` 会按照数组方式销毁全部元素并释放对应内存。

## 4. 对象生命周期

生命周期表示一个对象从开始存在到被销毁的时间范围。

栈中局部对象：

```text
进入作用域 → 开始存在
离开作用域 → 自动销毁
```

堆中动态对象：

```text
new 成功 → 开始存在
delete 执行 → 生命周期结束
```

指针变量的生命周期和它指向对象的生命周期并不相同。即使指针变量仍然存在，它指向的对象也可能已经被释放。

## 5. 常见动态内存错误

### 内存泄漏

```cpp
int* p = new int(10);
p = new int(20);
```

第一次申请的地址被覆盖，程序失去了释放第一块内存的途径，形成内存泄漏。

长期运行的嵌入式程序内存有限，持续泄漏可能导致内存耗尽、程序异常或设备需要重启。

### 悬空指针

```cpp
int* p = new int(10);
delete p;
```

堆对象已经被释放，但 `p` 仍可能保存旧地址，因此 `p` 成为悬空指针。

### 释放后使用

```cpp
delete p;
std::cout << *p << '\n';
```

对象生命周期已经结束，继续解引用属于释放后使用，结果是未定义行为。

### 重复释放

```cpp
delete p;
delete p;
```

同一块内存被释放两次，属于未定义行为。

### 创建与释放方式不匹配

```cpp
int* numbers = new int[5];
delete numbers;
```

数组应当使用：

```cpp
delete[] numbers;
```

## 7. LeetCode 977：有序数组的平方

题目输入是一个非递减数组，需要返回每个元素平方后的非递减数组。

例如：

```text
输入：[-4, -1, 0, 3, 10]
输出：[0, 1, 9, 16, 100]
```

直接从左向右平方后不一定有序，因为负数平方后可能变成较大的正数。

采用双指针：

* `left` 指向数组最左端。
* `right` 指向数组最右端。
* `pos` 指向结果数组当前待写入的位置。
* 比较左右元素的平方。
* 将较大的平方写入结果数组末尾。
* 移动被选中一侧的指针。
* `pos` 每轮向左移动。

核心循环：

```cpp
while (left <= right)
{
    int leftSquare = nums[left] * nums[left];
    int rightSquare = nums[right] * nums[right];

    if (leftSquare > rightSquare)
    {
        result[pos] = leftSquare;
        ++left;
    }
    else
    {
        result[pos] = rightSquare;
        --right;
    }

    --pos;
}
```

复杂度：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```
